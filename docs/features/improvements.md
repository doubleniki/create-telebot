# Улучшения
## Реализовано
- CLI: добавлены `--skip-install`, `--package-manager <bun|npm|pnpm|yarn>`, проверка доступности ПМ, вывод подсказок при пропуске установки.
- CLI: добавлен dry-run (`--dry-run`) с планом действий.
- CLI: флаг `--no-emoji` для тихих логов без эмодзи.
- Шаблон бота: проверка `BOT_TOKEN`, обработка ошибок запуска, `bot.catch`.
- Webhook: `WEBHOOK_PATH` + health-check, `SET_WEBHOOK=true` для регистрации адреса, корректное логирование ошибок.
- Scenes: патчинг `src/index.ts` стал идемпотентным и совместим с актуальным шаблоном.
- Шаблоны вынесены в `bin/templates/base`, тесты проверяют целостность шаблонов.
- Добавлены скрипты lint/format/test (biome, bun test) и базовые тесты (шаблоны, вебхук/сцены).

## Следующие шаги
- Доработать dry-run до вывода диффов/планируемых изменений по файлам.
- Добавить опцию приглушения цветов/форматирования вывода.
- Расширить тесты: сценарии add-webhook/add-scenes с моками fs/exec, проверка CLI опций и dry-run.
